How does this work without an internet connection?
The application bundles lightweight, high-performance neural embeddings and vector similarity algorithms directly inside the installed binary. Once installed, it doesn't need to connect to OpenAI or any cloud server. You can literally turn off your Wi-Fi and it works perfectly.
Are my confidential files really private?
Yes, 100%. All document parsing, vector indexing, and answers occur strictly on your device's memory and local disk. No analytics, tracking, telemetry, or document snippets are ever sent across the network.
Do I need an OpenAI API key or any ongoing subscription?
No! You never need to purchase API tokens or sign up for third-party subscriptions. You pay once for the software license, and you own it forever.
What formats are supported?
Adobe PDF (.pdf), Microsoft Word (.docx, .doc), Plain Text (.txt), Markdown (.md), CSV spreadsheets (.csv), JSON data (.json), and Rich Text (.rtf, .html). You can also paste raw text or snippets directly.
What are the system requirements?
Windows 10 or Windows 11 (64-bit). Recommended: 8 GB RAM or higher and 4 GB free disk space for local neural weight storage.
